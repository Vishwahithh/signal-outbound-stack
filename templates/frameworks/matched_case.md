# matched_case: one approved result that solved the same problem

Status: real replies. One positive reply in our data came on this touch. Blind rounds showed that a case from an
unrelated problem reads as a template, so only use a case that matches.
Use for: email two, same thread, 3 to 5 days after email one.

```
{first name},

{one sentence: an approved case from the proof list whose problem matches the question in email one, told as plain
fact with the fixed numbers exactly as the proof list gives them; never name the client}

{one line repeating the ask from email one in different words, answerable with one word}

{sender first name}
```

Must not: use a case whose problem differs from the email's question, add anything to the case, or name the client.
If no case matches, use second_angle instead.
